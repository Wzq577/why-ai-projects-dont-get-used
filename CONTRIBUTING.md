# Contributing

This is an ongoing research project about why AI projects do not get sustained use.

The most useful contribution is not a new idea.

It is a real AI project that was built but did not become something people repeatedly used.

## Good Contributions

- failed or low-use AI products
- GPTs that people tried once and abandoned
- agents that were impressive but not adopted
- AI tools with unclear users
- counterexamples that challenge the framework

## Submit a Case

Use the [submission template](templates/submission_template.md).

You can also open an issue with the case submission template.

## Privacy

You may anonymize:

- project name
- author name
- company name
- user details
- metrics

The goal is to preserve diagnostic value, not expose people.

## How Cases Are Analyzed

Cases are reviewed with this flow:

```text
User
↓
Task
↓
Result
↓
ChatGPT substitutability
↓
Failure mode
↓
Smallest useful improvement
```

## Counterexamples

Counterexamples are welcome.

If a project contradicts the current framework, that is useful evidence.
