# AI 想法风险评分体系 v0.1

目标：不只判断一个 AI 项目死在哪里，还判断问题有多严重。

所有维度都按 0-5 分评分。

分数越高，项目越健康。

```text
0 = 极弱
5 = 极强
```

## 四个核心维度

1. 用户明确度
2. 低输入成本
3. 结果强度
4. ChatGPT 抗替代性

总分满分 20 分。

## 1. 用户明确度

| 分数 | 标准 | 示例 |
| --- | --- | --- |
| 0 | 所有人 | AI 助手 |
| 1 | 大类人群 | 学生、创业者、自媒体人 |
| 2 | 具体身份 | 大学生、小商家、职场人 |
| 3 | 具体身份 + 明确场景 | 考研学生、淘宝店主、公众号作者 |
| 4 | 具体身份 + 明确场景 + 强任务 | 计算机考研学生写复试材料 |
| 5 | 具体身份 + 具体时刻 + 强痛点 | 正在写文献综述的计算机考研学生 |

## 2. 低输入成本

| 分数 | 标准 | 示例 |
| --- | --- | --- |
| 0 | 几乎无法开始 | 要先配置系统、接口、权限、参数 |
| 1 | 输入复杂 | 要填大量背景、目标、风格、限制 |
| 2 | 需要组织材料 | 要整理文档、案例、需求后再输入 |
| 3 | 可以用模板开始 | 填少量字段或选择预设模板 |
| 4 | 上传文件或粘贴链接即可 | 上传录音、简历、PDF、URL |
| 5 | 一句话即可开始 | 输入一句问题或需求 |

## 3. 结果强度

| 分数 | 标准 | 示例 |
| --- | --- | --- |
| 0 | 没有明确结果 | 聊完就结束 |
| 1 | 建议 | 方向、提醒、灵感 |
| 2 | 思路或摘要 | 大纲、总结、分析 |
| 3 | 草稿 | 初稿、方案、半成品 |
| 4 | 成品 | 可发布、可投递、可编辑、可复习 |
| 5 | 直接交付 | 文件、音轨、海报、PPT、自动写入系统 |

## 4. ChatGPT 抗替代性

| 分数 | 标准 | 示例 |
| --- | --- | --- |
| 0 | 完全替代 | 复制一句 Prompt 就能做 |
| 1 | 大部分替代 | ChatGPT 能做 80% 以上 |
| 2 | 可明显替代 | ChatGPT 能做 60% 左右 |
| 3 | 部分替代 | ChatGPT 能做基础版，但缺少语境或流程 |
| 4 | 难替代 | 需要外部工具、文件、平台或数据源 |
| 5 | 几乎无法替代 | 深度连接真实系统，并能完成交付动作 |

## 总分解释

| 总分 | 判断 | 含义 |
| --- | --- | --- |
| 0-6 | 高危 | 基本是功能演示或 Prompt 包装 |
| 7-10 | 弱机会 | 有局部价值，但核心问题严重 |
| 11-14 | 可测试 | 有明确切口，值得做小样本验证 |
| 15-17 | 强机会 | 用户、结果、替代性至少两项很强 |
| 18-20 | 高潜力 | 目标清晰、结果强、能接真实系统或流程 |
