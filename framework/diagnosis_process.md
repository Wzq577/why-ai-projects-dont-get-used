# AI 想法评审流程 v2

v1 回答：

```text
一个 AI 想法常见死因是什么？
```

v2 回答：

```text
拿到一个 AI 想法后，应该按什么顺序判断？
```

## 标准流程

```text
用户
↓
任务
↓
结果
↓
ChatGPT 替代性
↓
死亡原因
↓
成功机会
```

## 第一步：用户是谁

要问：

```text
谁会打开？
什么时候打开？
为什么是现在？
```

坏信号：

- 所有人都能用
- 学生都能用
- 创业者都能用
- 自媒体人都能用

好信号：

- 研究生写文献综述时
- 飞书团队整理会议纪要时
- 应届生投递某个岗位前
- 电商运营发布活动图前

## 第二步：任务是什么

要问：

```text
用户真正想完成什么？
```

表面任务经常是假的。

例如：

```text
AI 简历
```

表面任务：

```text
优化简历
```

真实任务：

```text
获得面试
```

## 第三步：结果是什么

要问：

```text
用户用完以后，手里多了什么？
```

如果回答不出来，项目危险。

判断重点：

- 输出能不能直接用
- 用户能不能立刻判断好坏
- 用完后是否留下可保存、可提交、可发布、可执行的东西

## 第四步：为什么不用 ChatGPT

要问：

```text
普通 ChatGPT 能做到几成？
用户为什么要多打开一个入口？
```

这一步必须放在用户、任务、结果之后。

因为如果不知道用户到底是谁、任务到底是什么、结果到底是什么，就无法判断 ChatGPT 替代性。
