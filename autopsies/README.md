# Autopsies

This folder contains external autopsies of public AI projects.

## Important Boundary

These are not definitive judgments about the authors or the projects.

They are external observations based only on public repository information:

- README
- repository metadata
- visible project structure
- public positioning

No author interviews are included unless explicitly stated.

## Why Low-Attention GitHub Projects?

Many AI projects are built with real effort but do not spread.

Low-attention repositories can reveal patterns that polished success stories hide:

- unclear users
- high setup cost
- outputs that stop at summaries or drafts
- missing workflow integration
- trust problems around execution

## Format

Each batch contains:

- sample overview table
- individual autopsies
- likely cause
- survival path
- batch observation
