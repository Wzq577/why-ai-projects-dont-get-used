## Launch Threshold

The project is ready to publish when these are done:

- [x] README explains the research question clearly
- [x] Personal/private projects are not in the public version
- [x] Framework files are separated from evidence
- [x] Autopsy batches are separated from findings
- [x] Submission template exists
- [x] Issue template exists
- [x] License exists
- [x] Trust cost of execution AI is documented
- [ ] Final privacy scan
- [ ] Final link/path scan

## What Not To Do Before Launch

- Do not add Batch 04
- Do not search for more GitHub cases
- Do not create a new framework version
- Do not wait for real user-submitted cases
- Do not turn this into a course, product, or prompt collection

## After Launch

Future updates can include:

- real submitted cases
- counterexamples
- stronger category-level analysis
- revisions to the scoring system
- more evidence for the trust cost of execution AI
