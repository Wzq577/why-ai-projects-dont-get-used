# Submission Template

If you built an AI project that did not get sustained use, you can submit it with this format.

You may anonymize names, links, users, or company details.

```text
Project name:

One-sentence description:

Target user:

When would the user open it:

What did the user ultimately want:

How do they solve it today:

Why not just use ChatGPT:

What happened after launch:

Any user feedback:
```

## Optional

```text
Project link:

Screenshots:

Number of users:

Retention or usage:

What you think went wrong:
```
